# Componentes de terceiros

O código-fonte de terceiros **não** está neste repositório. O `tools/fetch_third_party.sh` baixa cada componente nas versões fixadas, e cada um continua sob a própria licença.

| Componente | Uso | Licença |
|---|---|---|
| [ReShade API headers](https://github.com/crosire/reshade) (`runtime-asi/src/reshade_api/`) | API de add-on e overlay | BSD-3-Clause |
| [Dear ImGui](https://github.com/ocornut/imgui) | UI do overlay (headers v1.92.5-docking no addon) | MIT |
| [dualsensitive](https://github.com/tpetsas/dualsensitive) | HID do DualSense | MIT |
| [MinHook](https://github.com/TsudaKageyu/minhook) | hooks | BSD-2-Clause |
| [PortAudio](https://github.com/PortAudio/portaudio) | áudio de 4 canais | MIT |
| [nlohmann/json](https://github.com/nlohmann/json) | parser dos manifestos | MIT |
| [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS) | ponte de eventos do MOD de exemplo (Expedition 33) | MIT |
